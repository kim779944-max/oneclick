# 교환·급매 전문관 (교환급매물.com)

부동산 교환·급매 매물 108건(본선 92건 + 11.14 카페 스캔 신규 16건) 포털의 **보관용 원본**입니다.
도메인 `교환급매물.com` 은 예스닉 301 포워딩으로 별도 호스팅(ship.place)을 가리키고 있어,
이 폴더는 (1) 소스 보관 (2) 영구 대체 주소 `https://autooneclick.com/exchange/` 두 가지 역할을 합니다.

- 상단 4칸 도구줄: `4대 공부(/gongbu/)` · `전자명함(/bizcard/)` · `5초 계약서(/contract/)` · `KTS 전체`
  - 매물 상세의 `4대 공부` 는 그 물건 주소를 `/gongbu/?q=<주소>` 로 그대로 넘깁니다.
- 사진은 `img/p001.jpg ~ p092.jpg` 의 **1200×250 스트립 1장 = 3면**(실사 위성 / 확대 위성 / 지도)입니다.
  CSS 로 `width:300%` + `left:0 / -100% / -200%` 로 잘라 각 면을 씁니다 (원본 데이터 그대로).
- 2026-11-26 정비: 2열 사진 그리드 · 사진 대문창 상세(3면 갤러리) · 6단 권리분석 접기/펼치기 ·
  A4 1장 인쇄(화면에선 숨김, 인쇄에서만 표시) · 신규 16건은 사진이 없어 납작한 한 줄 목록.
